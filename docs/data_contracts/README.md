# SmartMaint Source Data Model

SmartMaint integrates industrial maintenance master data, maintenance events,
and IoT sensor measurements into a unified data platform.

## Source datasets

### equipment

Master dataset containing information about industrial equipment.

- Source: PostgreSQL maintenance system
- Grain: one row per equipment
- Primary key: `equipment_id`

### maintenance_events

Maintenance interventions and equipment failure events.

- Source: PostgreSQL maintenance system
- Grain: one row per maintenance intervention
- Primary key: `maintenance_id`
- Foreign key: `equipment_id` → `equipment.equipment_id`

### sensor_measurements

Time-series IoT measurements generated by industrial equipment.

- Source: CSV sensor files
- Grain: one measurement per equipment and timestamp
- Primary key: `measurement_id`
- Foreign key: `equipment_id` → `equipment.equipment_id`
