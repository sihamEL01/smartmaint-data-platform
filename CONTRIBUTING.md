# Contributing to SmartMaint

## Jira workflow

Every code change must correspond to a Jira ticket.

## Branch naming

Use one branch per ticket:

- `feature/SM-XX-description`
- `fix/SM-XX-description`
- `docs/SM-XX-description`
- `chore/SM-XX-description`
- `ci/SM-XX-description`

Example:

```text
chore/SM-16-initialize-github-repository
